Procedures

  • BasicTools[Setup]({InitTextFiles,printout}) package setup taking _rest as sequence of keywords or initializing equations for them exactly as in Maple interface command employing ProcessSetupArgs command. The list of recognized keywords (variables and constants) can be printed with printout option. These keywords are explained in the description of their corresponding commands. There is one special keyword-constant version common for all packages. Note that keyword values are not checked. Also, because many packages have their own Setup command, always use long name.
